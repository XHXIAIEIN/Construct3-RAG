# data/ Directory

Project data files. Contains external resources, generated schemas, and analysis artifacts.

## Subdirectories

| Subdirectory | Content | Size | Description |
|--------------|---------|------|-------------|
| `source/` | Translation CSV | Small | `zh-CN_r473.csv`, official Construct 3 translation file |
| `schemas/` | ACE Schema JSON | Medium | Generated by `scripts/generate-schema.js`; contains plugins/behaviors/effects/editor/features |
| `project_analysis/` | Project analysis artifacts | ~28MB | Generated by `scripts/analyze_projects.py`, used for RAG retrieval |
| `eventsheet_analysis/` | Event sheet analysis artifacts | ~33MB | Generated by `scripts/analyze_eventsheets.py`, used by event sheet generator |

## Notes

- `source/` CSVs come from external repos (Construct 3 translation); do not edit manually
- `schemas/` are auto-generated; regenerate via `generate-schema.js` instead of editing directly
- Analysis directories support incremental updates (no need to rebuild from scratch)
- Large directories (`project_analysis/`, `eventsheet_analysis/`) are in `.gitignore`
